# Why destination was made optional in step 1: we tried the split in a throwaway copy of the project first,
# with destination still required. Going forward worked, but the rollback of 0005 crashed with:
#   django.db.utils.IntegrityError: NOT NULL constraint failed: new__travelbuddy_trip.destination
# The rollback adds the column back before the data migration can fill it, and a required column can't be empty.
# Making it optional first fixed this, as Step 4 above shows.
